# AI Knowledge Platform

A production-grade AI Knowledge Platform built from scratch to demonstrate industry-standard AI Engineering, Machine Learning Engineering, Software Engineering, and MLOps practices.

## Project Goals

- Build a scalable AI application from first principles.
- Follow production-quality architecture and engineering practices.
- Learn not only how to build AI systems, but why they are designed that way.
- Document every major technical decision throughout development.

## Planned Technology Stack

- FastAPI
- PostgreSQL
- Qdrant
- Ollama
- SQLAlchemy
- Docker & Docker Compose
- Python
- Git & GitHub
